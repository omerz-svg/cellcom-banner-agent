# סוכן הבאנרים של סלקום

סוכן שמעצב באנרים לאתר של סלקום ישירות בפיגמה. הוא מכיר את כל הטמפלייטים של מערכת העיצוב (מידות, אזורי חיתוך, אזורי טקסט, כללי מסירה), את שפת הקמפיינים מ-45 עמודי Campaigns, כותב קופי בעברית בקול של סלקום, ומייצר ומטמיע תמונות.

## התקנה
1. מתקינים את התוסף ב-Claude (Customize, ואז Plugins, ואז העלאת התיקייה או ה-zip).
2. מחברים את **Figma** ב-Settings → Connectors (חובה). צריך גישה לקבצים "Design System" ו-"Campaigns" של צוות Cellcom Digital, עם הספריות "Design System" ו-"Website Design 2026".
3. **Magnific** מוגדר בתוסף. בפעם הראשונה מתחברים לחשבון (Business) בחלון שנפתח.
4. כלים מקומיים חינמיים (אופציונלי): בטרמינל, מתוך תיקיית הסקיל `skills/cellcom-banners`:
   - `zsh setup.sh`: הסרת רקע (rembg) והגדלה (Real-ESRGAN), כ-230MB.
   - `zsh setup.sh --flux`: גם יצירת תמונות מקומית (Z-Image Turbo), עוד כ-6GB.

## שימוש
"תעצב באנר מרקטינג ל-5G PRO, דסקטופ ומובייל", "עוד אופציה לבאנר הזה: <לינק לפיגמה>", "קרוסלת הירו לסיבים".

ייצוא: "תייצא את הבאנרים מהלינק הזה: <לינק לפיגמה>". הקבצים נשמרים כ-JPEG עד 200KB לתיקייה ב-`~/Desktop/שיווקי סלקום`. בקרוסלת הבית דסקטופ ב-x2 ומובייל ב-x4, ושאר הפריימים לפי הגדרת הייצוא שלהם בפיגמה.

## מה בפנים
- `agents/cellcom-banner-agent.md`: הסוכן.
- `skills/cellcom-banners/`: הידע (טמפלייטים, מותג, שפת קמפיינים, תמונות, תהליך פיגמה), סקריפטי ההעתקה בין קבצים, והכלים המקומיים.
- `skills/export-campaign-images/`: סוכן הייצוא. מייצא פריימים מפיגמה ודוחס כל קובץ עד 200KB בלי לשנות מידות (דורש macOS).
- `.mcp.json`: חיבור ל-Magnific.

הפונט RAG-Sans-Cellcom לא כלול בתוסף. הוא נטען מפיגמה.
