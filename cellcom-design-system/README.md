# מערכת העיצוב של סלקום (DESIGN.md)

`DESIGN.md` הוא קובץ אחד שכל סוכן AI קורא ומעצב לפיו: Claude, Claude Design, Cursor, v0, Lovable. הוא כולל צבעים, טיפוגרפיה, רכיבים, שפת קמפיינים, כללי באנרים וקול הקופי.

- `tokens.json`: כל הטוקנים, עם הערות שימוש בעברית.
- `assets/`: לוגו לבן (מקור), לוגו סגול (צבע מחדש, ממתין לאישור), והגל הסגול.
- `fonts/`: RAG-Sans-Cellcom. **ברישיון של סלקום, לשימוש בעבודה לסלקום בלבד. הפונטים לא נמצאים בריפו: צריך להעתיק אותם ידנית לתיקייה הזו מהקובץ cellcom-kit.zip.**

שימוש: לצרף את `DESIGN.md` לשיחה או לפרויקט, ולבקש "עצב לפי ה-DESIGN.md".
